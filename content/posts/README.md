# Blog Content

Folder ini disiapkan untuk artikel blog.

Saran format awal:

- satu file per artikel
- gunakan nama file berbasis slug, misalnya `membangun-admin-panel.md`
- simpan metadata seperti judul, tanggal, tag, dan status di bagian atas file

Contoh metadata sederhana:

```md
---
title: "Membangun ulang website portofolio"
slug: "membangun-ulang-website-portofolio"
status: "draft"
date: "2026-04-16"
tags: ["portfolio", "blog", "rebuild"]
---
```
